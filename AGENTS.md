# Repository Guidelines

The working guide for this repository is **[CLAUDE.md](CLAUDE.md)**: project structure, build
and test commands, architecture, coding style, testing rules, release process and security
constraints all live there, in one place.

Read that file before making changes. It is kept as the single source so the two documents
cannot drift apart.

User-facing documentation is in `README.md`, `CHANGELOG.md` and `UPGRADE.md`.
